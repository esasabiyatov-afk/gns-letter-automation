ГНС — ПОРТАТИВНАЯ СБОРКА

1. Полностью скопируйте или распакуйте всю папку GNS-Portable.
   Не переносите отдельно EXE и папку _internal.
2. Дважды щёлкните START.bat либо GNS-Portable.exe.
3. Приложение откроется в системном браузере по адресу http://127.0.0.1:8765.
   Окно терминала не открывается. Python, pip, GitHub и интернет для запуска
   не требуются.
4. Рабочие данные сохраняются только в папке runtime рядом с EXE.
   Входящие PDF можно помещать в папку Входящие рядом с EXE.

ИКОНКИ
- У GNS-Portable.exe встроен вариант «Документ + печать».
- В папке Иконки лежат все три варианта для ярлыка на рабочем столе.
- У EXE значок меняется только новой сборкой. Для ярлыка: правый клик по
  ярлыку → Свойства → Сменить значок → выберите файл .ico из папки Иконки.

В сборку уже включены:
- Python и все библиотеки приложения;
- локальный OCR (русский и кыргызский, fast и best);
- QR/PDF-компоненты;
- шаблон одиночного и множественного Word-ответа;
- локальные справочники УГНС.

ДЛЯ ОТДЕЛЬНЫХ ФУНКЦИЙ НУЖНО НА РАБОЧЕМ КОМПЬЮТЕРЕ
- Microsoft Outlook с настроенным почтовым профилем — для почты;
- в текущей тестовой версии все исходящие письма принудительно отправляются
  только на esensabiyatov@gmail.com;
- драйвер WIA — для сканирования с МФУ;
- доступ к разрешённым серверам ГНС, АБС и реестров — для QR, АБС и сверок.

СОВМЕСТИМОСТЬ ЭТОЙ СБОРКИ
- Windows 8.1 x64 и новее. 32-битная Windows не поддерживается.
- Outlook 2013 и новее: разрядность Outlook не важна, нужен настроенный
  профиль в этом же Windows-пользователе.
- Браузер Chrome/Chromium или Firefox. Internet Explorer 11 не подходит для
  современного интерфейса приложения.

Не удаляйте папку runtime, если нужно сохранить историю, настройки и
созданные ответы. Для переноса работы на другой компьютер переносите всю
папку GNS-Portable вместе с runtime и Входящие.
