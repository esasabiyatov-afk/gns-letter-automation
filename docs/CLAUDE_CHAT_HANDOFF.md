# Пакет для Claude Chat

Этот архив предназначен для продолжения разработки проекта в Claude Chat.
Это локальное приложение Windows для обработки PDF-писем ГНС.

## Как начать разговор

Загрузите ZIP в Claude Chat и отправьте:

> Продолжи разработку проекта. Сначала изучи `docs/PRODUCT_SPEC.md`,
> `docs/ARCHITECTURE.md`,
> `docs/DEVELOPMENT_AUTOPILOT.md` и `AGENTS.md` целиком. Затем изучи
> `src/gns_app/services/workflow.py`, `main.py` и тесты. Не предлагай
> угадывание реквизитов: QR — первичный источник, затем OCR, затем ручная
> проверка. Кыргызские буквы должны сохраняться без подмены. Сначала кратко
> перечисли текущее устройство проекта и риски, затем отвечай на мой запрос.

## Состав пакета

- `src/` — исходный код приложения;
- `tests/` — автоматические тесты;
- `docs/` — продуктовая спецификация, архитектура и журнал разработки;
- `УГНС/` — шаблоны Word и примеры писем PDF;
- `models/` — локальные модели Tesseract: `rus`, `kir`, `osd` в вариантах
  `tessdata_fast` и `tessdata_best`;
- `README.md`, `pyproject.toml`, `scripts/` — запуск и зависимости.

## Намеренно исключено

- `runtime/` — рабочая база SQLite, результаты распознавания, журналы и
  производные файлы;
- `.venv/` и собранные приложения;
- рабочие PDF вне каталога `УГНС/`, чтобы не передавать текущие документы
  банка и рабочую базу.

## OCR

Приложение использует Tesseract с языками `rus+kir` и `osd`.
По умолчанию ожидаются каталоги:

```text
%LOCALAPPDATA%\GNSLetterAutomation\models\tessdata_fast
%LOCALAPPDATA%\GNSLetterAutomation\models\tessdata_best
```

В архиве эти каталоги находятся в `models/`. Для запуска в иной среде нужно
либо скопировать `models/` по указанному пути, либо установить переменную
окружения `GNS_OCR_MODEL_DIR` на путь к каталогу `models/`.

## Важные правила

1. Ни один PDF и ни одна страница не должны исчезать из учёта.
2. Не восстанавливать буквы, цифры, ИНН и даты догадкой.
3. При успешном QR данные официального документа имеют приоритет.
4. Если QR не получен, использовать OCR; при сомнении — ручная проверка.
5. Решение STI-010 не должно блокировать письмо.
6. Не отправлять документы во внешние сервисы без отдельного решения.
7. Не включать реальные логины или пароли АБС в код, тесты или журнал.

## Текущая договорённость по интерфейсу

- Найденные в АБС/ОДБ лица показываются только списком для ручного ответа;
  Word для них сотрудник готовит вне приложения.
- Не найденные лица группируются по адресату и получают автоматический Word.
- ОДБ отмечается в списке кнопками `✓ Есть` и `× Нет`.
- Тестовая АБС автоматически проверяет новое подтверждённое письмо; старые
  обращения не должны массово запускаться при старте программы.
