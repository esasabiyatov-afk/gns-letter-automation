# Автоматизация обработки писем ГНС

Локальное приложение для Windows с русским интерфейсом. Приложение принимает
пакетные PDF, ведёт постраничный учёт, читает QR, создаёт очередь проблемных
страниц, выполняет тестовую проверку АБС и готовит ответы Word по существующим
шаблонам.

## Текущий статус

Разрабатывается безопасный MVP. В первой версии предусмотрены:

- загрузка PDF;
- регистрация каждой страницы;
- просмотр конкретной страницы как отдельного PDF, улучшенного изображения и
  выделяемого OCR-текста;
- многопроходное чтение QR;
- классификация страниц с результатом «не определено» и автоматическое
  завершение уверенно распознанных решений STI-010;
- очередь ручной проверки;
- ручной ввод реквизитов;
- выбор или добавление исполнителя сразу на стартовой странице;
- фейковая АБС без сохранения логина и пароля;
- единая пакетная проверка АБС за текущий день;
- автоматическая последовательная сверка OCR-данных с ОсОО.KG по ИНН;
- ручной поиск ОсОО.KG по ИНН или названию с отображением руководителя;
- этап ручной проверки ОДБ после АБС для периода раньше порога;
- загрузка новых PDF из локальной папки `Входящие`;
- получение новых PDF-вложений из выбранного локального ящика Outlook от
  разрешённых отправителей с постоянным реестром повторов, без макроса внутри
  Outlook;
- журнал обработки;
- локальный справочник налоговых органов с безопасными подсказками района и
  места;
- подготовка общего Word-ответа по налоговому органу и адресату.

Для сканов без полного официального документа используется локальный
Tesseract `rus+kir`. По умолчанию работает быстрая модель `fast`; модель
`best` сотрудник может отдельно запустить для проблемной страницы. Кыргызские
символы сохраняются как Unicode.

Любые ИНН, наименование и период из OCR являются только предзаполненными
подсказками. Они не разрешают автоматический ответ и требуют обязательной
посимвольной сверки с изображением.

После АБС приложение сортирует обращения текущего дня по налоговому органу и
адресату. Все лица, не найденные в АБС, попадают в один ответ этому адресату.
Найденные лица показываются отдельной группой и не подставляются в шаблон
«счетов нет».

Для готового ответа русская должность адресата автоматически переводится в
дательный падеж. Исходная должность сохраняется без изменений и показывается
рядом с формой, которая будет подставлена в Word.

Если встроенный текстовый слой русско-кыргызского PDF повреждён и содержит
латиноподобную абракадабру, приложение отклоняет его и запускает локальный
OCR. Полностью извлечённые данные официального документа по проверенному QR
не требуют ручного подтверждения: страница сразу получает статус «Успешно».

Для OCR без официальной версии по QR приложение последовательно сверяет
каждый распознанный ИНН с ОсОО.KG и показывает совпадение названия,
официальное название и руководителя. Полный PDF, полный OCR-текст и банковские
данные наружу не передаются. Ручной экран также поддерживает поиск по ИНН или
названию. Расхождение или недоступность реестра блокируют автоматический
маршрут до явного решения сотрудника; название из реестра не подменяется молча.

Если начало периода раньше установленного порога, сначала выполняется АБС,
затем обращение попадает в отдельную очередь ОДБ. Сотрудник вручную отмечает
результат ОДБ по каждому ИНН. Общий Word нумерует всех включённых лиц.

Превью записывается в базу сразу после отрисовки страницы. Если сервер
официального документа по QR не ответил вовремя, изображение остаётся
доступным сотруднику, а выбранную страницу можно запустить повторно.

Решение со скана считается уверенно распознанным только при одновременном
наличии нескольких независимых признаков STI-010, достаточном качестве и
явном превосходстве признаков решения над признаками письма. Такое решение не
требует ручного подтверждения, если в том же PDF есть письмо. Сомнение в типе
или пакет без письма остаются в ручной очереди.

Если OCR пропустил надпись `STI-010`, решение также может быть принято по
устойчивой структуре формы: характерному заголовку, фразам разделов и минимум
трём отдельным служебным кодам. Цифры внутри ИНН кодами формы не считаются.
После обновления приложения старые неподтверждённые решения безопасно
пересчитываются по актуальным правилам.

Ссылка на `Решение STI-010` внутри текста письма не является доказательством
типа страницы. Для автоматического решения дополнительно обязательны признаки,
характерные именно для таблицы решения, и отдельные служебные коды.

Справочник налоговых органов хранится только в локальной SQLite. Совпадение по
OCR используется как подсказка лишь тогда, когда найден ровно один точный
вариант; неоднозначное совпадение не заполняется автоматически. При ручном
вводе сотруднику доступен список сохранённых района и места.

## Технологический подход

- Python 3.12;
- локальный FastAPI-сервер;
- HTML/CSS/JavaScript без внешних CDN;
- SQLite;
- pypdf и pypdfium2;
- локальный QR-декодер;
- python-docx и безопасное OOXML-заполнение;
- будущая упаковка в Windows EXE.

Приложение слушает только локальный интерфейс и не требует публичного хостинга.

## Локальный запуск

### Простой способ (Windows)

Дважды кликните `START.bat` в корне проекта. Скрипт сам:
- проверит, что установлен Python 3.12 (и подскажет ссылку на скачивание,
  если его нет или стоит другая версия);
- создаст виртуальное окружение и поставит все зависимости;
- поставит `tesserocr` (готовый wheel под Windows);
- разложит модели распознавания текста (`rus`/`kir`/`osd`) — сначала из
  папки `models/` в архиве, а если чего-то не хватает, докачает из интернета;
- запустит сервер на `http://127.0.0.1:8765`;
- перезапустит сервер после аварийного завершения и не позволит запустить
  вторую копию приложения.

Повторный запуск того же `START.bat` работает быстро — все уже установленные
шаги он пропускает и сразу переходит к старту сервера.

### Вручную через PowerShell

Тот же результат по шагам, если нужен больший контроль или отладка:

Первичная подготовка:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
```

Запуск:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_dev.ps1
```

После запуска (любым из двух способов) откройте `http://127.0.0.1:8765`.
Для проверки:

```powershell
.\.venv\Scripts\python.exe -m pytest
```

Рабочие копии, превью, журнал SQLite и созданные ответы сохраняются только в
локальной папке `runtime`. Исходные PDF и Word-шаблоны не изменяются.

### Read-only подключение Tolubay АБС

До завершения офисной проверки приложение использует тестовый адаптер. Реальный
режим включается только в окружении процесса:

```powershell
$env:GNS_ABS_MODE = "tolubay"
$env:GNS_TOLUBAY_BASE_URL = "https://ob.tolubay.kg"
# Только если в офисе используется отдельный доверенный корневой сертификат:
$env:GNS_TOLUBAY_CA_FILE = "C:\path\to\office-ca.pem"
```

Логин и пароль не задаются переменными окружения и не сохраняются в файлах,
БД или журнале. Пользователь вводит их в приложении для каждой отдельной
проверки; TLS-проверка не отключается. Для единственной точной анкеты адаптер
читает активные и закрытые счета, но приложение сохраняет только их количество
и всё равно требует от сотрудника подтвердить наличие счёта вручную.
