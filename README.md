# Автоматизация обработки писем ГНС

Локальное приложение для Windows с русским интерфейсом. Приложение принимает
пакетные PDF, ведёт постраничный учёт, читает QR, создаёт очередь проблемных
страниц, выполняет тестовую проверку АБС и готовит ответы Word по существующим
шаблонам.

## Текущий статус

Разрабатывается безопасный MVP. В первой версии предусмотрены:

- загрузка PDF;
- регистрация каждой страницы;
- локальное создание превью;
- многопроходное чтение QR;
- классификация страниц с результатом «не определено»;
- очередь ручной проверки;
- ручной ввод реквизитов;
- фейковая АБС без сохранения логина и пароля;
- журнал обработки;
- подготовка одиночного и множественного ответа Word.

Для сканов без текстового слоя используется локальный Tesseract `rus+kir`.
Быстрая и точная модели сравниваются локально, кыргызские символы сохраняются
как Unicode. Результат OCR остаётся подсказкой и требует подтверждения
сотрудника.

Если встроенный текстовый слой русско-кыргызского PDF повреждён и содержит
латиноподобную абракадабру, приложение отклоняет его и запускает локальный
OCR. Полностью извлечённые данные официального документа по проверенному QR
не требуют ручного подтверждения: страница сразу получает статус «Успешно».

## Технологический подход

- Python 3.12;
- локальный FastAPI-сервер;
- HTML/CSS/JavaScript без внешних CDN;
- SQLite;
- pypdf и pypdfium2;
- локальный QR-декодер;
- python-docx и безопасное OOXML-заполнение;
- будущая упаковка в Windows EXE.

Приложение слушает только локальный интерфейс и не требует публичного хостинга.

## Локальный запуск

Первичная подготовка:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
```

Запуск:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_dev.ps1
```

После запуска откройте `http://127.0.0.1:8765`. Для проверки:

```powershell
.\.venv\Scripts\python.exe -m pytest
```

Рабочие копии, превью, журнал SQLite и созданные ответы сохраняются только в
локальной папке `runtime`. Исходные PDF и Word-шаблоны не изменяются.
